# Barista Pro 3000 User Manual

## Descaling

Descale the machine every 3 months, or when the orange DESCALE light turns on. Use only citric-acid-based descaling solution.

## Troubleshooting

Error code E7 means the water tank is not seated correctly. Error code E9 indicates the grinder is blocked.

## Warranty

The warranty period is 24 months from the date of purchase and does not cover damage caused by limescale.
