# v0.3 heading detection in manual-style PDFs (step 53)

Step 52 recognises heading lines in TXT and PDF. On a real appliance manual
(an English clock-radio PDF of the owner, private, not in the repository) it
found 105 headings, almost all wrong: diagram labels set in capitals
(`TIME SET`, `FWD FAST REV`), several labels joined into one "wrapped" title,
form fields (`DATE OF PURCHASE DEALER NAME …`) and the lines of paragraphs
written in capitals, often ending in a word broken by a hyphen
(`ALL EXPRESS AND IMPLIED WARRANTIES, INCLUDING THE WARRANTY OF MER-`).
Answers were still right, but sources showed these as their heading path.

Baseline engine: 0.3.0-alpha.4 (step 52; lexical query `prefix:3`, the stems
of step 51 are not adopted).

## Changes to try (all three together, decided before scoring)

1. A line ending in a word broken by a hyphen is not a heading.
2. At most two lines in capitals join into one title; a run of three or more
   lines in capitals is a label block or a paragraph in capitals, and all of
   its lines are body text.
3. A title in capitals (level 3, not a part or chapter) stays a heading only
   if what follows it is real text: it becomes body text when the next block
   is a paragraph with fewer than 20 letters, or one that starts with three or
   more words in capitals (the title was the first line of a paragraph in
   capitals). Checked over the whole document, so a title at the foot of a
   PDF page keeps its body on the next page.

## Decision rule (written on 2026-10-14, before any number was produced)

This rule is not changed after the numbers are in. There is one variant (the
three changes together); nothing is tuned, so holdout is read once with dev.

The change is adopted only if:

1. wins minus losses ≥ 0 on **dev** (v02, hybrid in context, paired per
   question against 0.3.0-alpha.4);
2. wins minus losses ≥ 0 on **holdout**;
3. no category loses more than 2 questions net (dev and holdout together);
4. `seed.jsonl`, `anayasa-tr.jsonl` and `anayasa-cekim-tr.jsonl` lose at most
   1 question net each;
5. on the four v02 documents with step 52 headings (`tr-anayasa.txt`,
   `tr-fiyat-listesi.txt`, `tr-sulama-katalogu.pdf`,
   `tr-yargitay-1cd-2016-347.pdf`) at least 95% of the step 52 headings are
   still headings;
6. on the owner's manual (checked locally, only counts recorded here) at most
   10 headings remain, every one of the 10 examples above is gone, and
   `IMPORTANT SAFETY INSTRUCTIONS` is still a heading.

`v02-answers.jsonl` is reported, not gated. If the rule fails, the parser
stays as in 0.3.0-alpha.4 and the result is recorded here.

## The 10 examples of rule 6

Taken from the owner's manual before scoring: `TIME SET`, `FWD FAST REV`,
`MODEL NUMBER SERIAL NUMBER`,
`DATE OF PURCHASE DEALER NAME DEALER ADDRESS TELEPHONE NUMBER`,
`TO PREVENT ELECTRIC SHOCK MATCH`, `DRIPPING OR SPLASHING AND THAT NO OB-`,
`RADIO ALARM RADIO/BUZZER RADIO ON OFF SELECTER SLEEP DOZE /SLEEP CANCEL`,
`THE WARRANTOR IS NOT LIABLE FOR INCIDENTAL OR CONSEQUENTIAL DAMAGES RE-`,
`ALL EXPRESS AND IMPLIED WARRANTIES, INCLUDING THE WARRANTY OF MER-`,
`PARTS AND SERVICE, WHICH ARE NOT COVERED BY THIS`.

## Result (2026-10-14): rejected, parsing stays as in 0.3.0-alpha.4

### First scoring (commit `97a17e6`)

Scored with the variant applied to 0.3.0-alpha.4 (`8cd36c3`); the commit that
records it sits on 0.3.0-alpha.5, whose parser is identical (step 51 changed
only the lexical query), so rules 5 and 6 reproduce from it exactly and rules
1-4 need the alpha.4 lexical mode (`prefix:3`).

| rule | result | pass |
|---|---|---|
| 1. dev net ≥ 0 | 0 (no question changed) | yes |
| 2. holdout net ≥ 0 | 0 | yes |
| 3. no category below −2 net | all 0 | yes |
| 4. older sets ≥ −1 each | seed 14/14, anayasa-tr 19/20, anayasa-cekim-tr 28/30, all unchanged | yes |
| 5. ≥ 95% of step 52 headings kept | 229 of 230 (99.6%) | yes |
| 6. owner's manual | 105 → 15; all 10 examples gone; `IMPORTANT SAFETY INSTRUCTIONS` kept | **no** |

**The scored code did not implement the spec in two places** (found by code
review after scoring): change 3 ran per PDF page, so a title at the foot of a
page was never checked against the next page; and the block-in-capitals mode
of change 2 carried on past blank lines. So this scoring did not test the
spec as written.

### Second scoring (commit `dc252e0`), the spec as written

Owner's protocol: Claude and `gpt-6-sol` (effort high) both recommended fixing
only those two deviations and scoring once more under the unchanged rule,
adopting only if all six rules pass. The manual had been seen by then, so
this is not an independent result. Scored on 0.3.0-alpha.5 (`731d81e`, lexical
`prefix:3+stem:7`) against the same engine with alpha.4 parsing.

| rule | result | pass |
|---|---|---|
| 1. dev net ≥ 0 | 0 (no question changed; hybrid in context 0.931 both) | yes |
| 2. holdout net ≥ 0 | 0 | yes |
| 3. no category below −2 net | all 0 | yes |
| 4. older sets ≥ −1 each | seed 14/14, anayasa-tr 19/20, anayasa-cekim-tr 29/30, all unchanged | yes |
| 5. ≥ 95% of step 52 headings kept | 229 of 230 (99.6%) | yes |
| 6. owner's manual | 105 → **16**; all 10 examples gone; `IMPORTANT SAFETY INSTRUCTIONS` kept | **no** (limit 10) |

Rule 6 fails again, so the variant is rejected and both experiment commits
are reverted. It is not regression-free either: in both scorings one step 52
heading is lost (the garbled catalogue title line
`DAMLA SULAMA ÜRÜN KATALOĞU - 2026 DÖRDÜNCÜ ÇEYREK`, demoted because the text
after it is short), within the 95% gate.

The headings that remain on the manual are mostly garbled diagram text
(letters of neighbouring labels interleaved by the PDF) and single labels.

**Known weaknesses of the variant, for a next attempt** (also from review):
change 3 counts one-letter words and acronyms (`A`, `USB`, `AC`) as capitals,
so `POWER SUPPLY` followed by `USB AC DC adapter …` would be demoted; and the
retraction drops the last block if it is not a heading (unreachable today,
but it should peek before popping). A next attempt is a new step with a new
rule written first; the owner's manual counts as seen, so its heading count is
a reported sanity check, not evidence; v02 rules 1-5 stay hard gates.
