# v0.1 seed evaluation (first D-007 data point)

The seed set (`eval/corpus/seed`, `eval/datasets/seed.jsonl`: 4 documents,
16 questions, 14 answerable, 3 of them cross-language) proves that the
pipeline works end to end with the default models. It is **too small to
choose models or settings**; the 200-question set in v0.2 decides (D-007,
D-018).

- Machine: Apple M5 Max, 128 GB RAM, macOS 26.4 (Metal)
- Date: 2026-10-05
- Version: `orag 0.1.0-alpha.31` (release build, the v0.1.0 candidate)
- Embedding model: `qwen3-embedding-0.6b-q8_0`
- Generation model: `qwen3.5-4b-q4_k_m`
- Source: `scripts/release-model-check.sh` (`target/release-seed-eval.json`);
  the gate requires hybrid recall@10 >= 0.9 and the evidence of `x-001`,
  `x-002`, `x-003` in the answer context.

## Retrieval

| strategy | recall@5 | recall@10 | MRR@10 | nDCG@10 | in context (top 8) | p50 ms | p95 ms |
|---|---|---|---|---|---|---|---|
| lexical | 0.857 | 0.857 | 0.857 | 0.857 | 0.857 | 0.3 | 0.4 |
| dense | 1.000 | 1.000 | 0.964 | 0.974 | 1.000 | 12.4 | 12.9 |
| hybrid | 0.929 | 1.000 | 0.939 | 0.952 | 1.000 | 12.4 | 12.8 |

Lexical search misses two cross-language questions, as expected: `x-001`
(an English question about a Turkish document) and `x-002` (a Turkish
question about an English document); dense and hybrid retrieval put every label in the
answer context.

## Generation speed (informational, D-018)

`orag serve` with the default packs, the seed corpus uploaded, one warm-up
query, then three streamed queries (`POST /v1/collections/1/query`,
`"stream": true`), timed by the client. Time to first token runs from the
request to the first `token` event and includes retrieval and prompt
processing. Decode rate is `(completion tokens - 1) / (total - time to first
token)`. The `trace` rate, `completion_tokens / generation_ms`, includes
prompt processing, so it mostly reflects answer length and understates
decoding.

| question | prompt tokens | completion tokens | time to first token | total | decode tokens/s | trace tokens/s | answer |
|---|---|---|---|---|---|---|---|
| İade süresi kaç gündür? | 594 | 12 | 0.19 s | 0.29 s | ~110 | 44.4 | İade süresi 14 gündür [1]. |
| How often should the machine be descaled? | 550 | 23 | 0.19 s | 0.36 s | ~129 | 66.1 | The machine should be descaled every 3 months, or when the orange DESCALE light turns on [1]. |
| ORX-7 cihazında timeout_seconds varsayılan değeri nedir? | 606 | 28 | 0.19 s | 0.41 s | ~123 | 71.4 | ORX-7 cihazında `timeout_seconds` parametresinin varsayılan değeri 30 saniyedir [1]. |

All three answers are correct and cite the right source.

Not measured for v0.1: generation speed on the Linux reference (x86-64 CPU)
and on a 16 GB M-series laptop. It is informational in v0.1; v0.2 sets the
target and measures both (D-018).
