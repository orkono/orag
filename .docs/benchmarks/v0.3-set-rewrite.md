# v0.2 set rewritten (step 49): new baseline

On the owner's decision the 200 questions and 60 answer probes of the v0.2 set
were written again by `claude-opus-5-5` and audited row by row by `gpt-6-sol`
(`eval/datasets/v02-audit.md`, D-018 amendment). The corpus, categories,
counts and split rules did not change. This file records the engine's numbers
on the new set; nothing is decided from them. Results on the Task 42 set
(`v0.2-model-decision.md`, `v0.3-fusion.md`) stay as they were measured.

Setup: `0.3.0-alpha.1` engine (fusion from step 48), release build on Apple
M5 Max (Metal), default models (`qwen3-embedding-0.6b-q8_0`,
`qwen3.5-4b-q4_k_m`).

```bash
orag eval retrieval --corpus eval/corpus/v02 --dataset eval/datasets/v02-retrieval.jsonl
orag eval answers --corpus eval/corpus/v02 --dataset eval/datasets/v02-answers.jsonl --sampler dry
```

## Reading

- Hybrid in context is 0.909 here against 0.943 on the old set with the same
  engine. The new set is harder where the old one was easy: multi-document
  questions (0.800 against 1.000) ask for evidence from documents that do not
  share vocabulary, and their MRR (0.260) shows the second label usually
  arrives late.
- Cross-language holds: hybrid equals dense (0.880), so the step 48 fusion keeps
  what dense finds. Lexical alone finds 0.200.
- Hybrid is never below dense in any category; accentless is the one place
  where lexical carries hybrid (dense 0.750).
- Weakest groups for v0.3: multi-document recall, and MRR on cross-language and
  multi-document questions.
