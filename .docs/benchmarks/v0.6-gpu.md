# v0.6 GPU bench

The one-button bench of the v0.6 GPU plan (Task 6, `.docs/plans/2026-10-21-orag-v0.6-gpu-plan.md`):
the desktop app answers the 10 pinned v0.2 dev questions (`eval/datasets/v06-bench.jsonl`) on
`orag` and on `orag-vulkan` and writes `orag-bench-<time>.json` (schema `orag-bench/1`). The
G-7 gate needs a real graphics card; this file collects the reference and the results.

## CPU reference (step 88d, 2026-10-22, run 39694258418)

The bench's own CPU runs (`orag eval bench`, sampler `dry`) on GitHub's `ubuntu-22.04` x86-64
runner, 4 vCPU: the v0.5 CPU reference machine (`v0.5-model-tiers.md`). The design note named
the owner's 6-core server; the GitHub runner was used instead so the floor sits on the same
machine as the v0.5 CPU figures. The floor compares which facts are found and where the model
abstains, which does not depend on the CPU's speed. Stored as `eval/bench/v06-cpu-reference.json`
and built into the desktop app.

| tier | generator | facts found | abstained (unanswerable) | load ms | p50 answer s |
|---|---|---|---|---|---|
| default | qwen3.5-4b-q4_k_m | 10 / 11 | 055, 058 (not 041) | 9 279 | 101.9 |
| large | qwen3.5-9b-q4_k_m | 11 / 11 | 058 (not 041, 055) | 4 961 | 167.0 |

The 4B misses the second fact of v2-ans-015; the 9B does not abstain on 041 and 055, as in
v0.5. On a PC, the bench's CPU floor holds when the CPU finds at least the reference's facts
minus one and abstains wherever the reference abstained.
