# v0.3 headings in plain text and PDF (step 52)

Markdown and DOCX documents carry their headings into chunks: a chunk starts at
a heading, and the heading path is embedded, indexed and shown with the source.
Plain text and PDF do not: every line is body text, so a constitution article
or a catalogue section gets no heading path and chunks cut across sections.
This step recognises heading lines in plain text and PDF page text.

Baseline engine: 0.3.0-alpha.3 (fusion of step 48, lexical query `prefix:3`;
the stems of step 51 are not adopted yet).

## Decision rule (written on 2026-10-14, before any variant was scored)

This rule is not changed after the numbers are in.

Variants are scored with `orag eval retrieval` on `eval/corpus/v02` +
`v02-retrieval.jsonl`, default models, hybrid strategy. Tuning looks at the
**dev** split only; holdout is read once, for the chosen variant. Results are
paired per question on "in context", against 0.3.0-alpha.3.

Headings also change what a user sees (a heading path on every source), so the
bar is "does not hurt retrieval", not "must gain". The chosen variant is
adopted only if:

1. wins minus losses ≥ 0 on **dev**;
2. wins minus losses ≥ 0 on **holdout**;
3. no category loses more than 2 questions net (dev and holdout together);
4. `seed.jsonl`, `anayasa-tr.jsonl` and `anayasa-cekim-tr.jsonl` lose at most
   1 question net each on hybrid in context;
5. on the affected v02 documents (`tr-anayasa.txt`, `tr-fiyat-listesi.txt`,
   `tr-sulama-katalogu.pdf`, `tr-yargitay-1cd-2016-347.pdf`) most chunks get a
   non-empty heading path, and a manual read of 30 detected headings finds at
   most 3 that are not headings.

`v02-answers.jsonl` is reported for the chosen variant (expected facts, valid
citations, abstention), not gated.

Variants (dev only), from the most conservative:

- **A** upper-case lines, `-- name --` lines;
- **B** A plus Roman-numeral and single-letter enumerations (`IV. Title`,
  `A. Title`);
- **C** B plus decimal enumerations (`1. Title`, `2.3 Title`).

If no variant passes, the parser stays as it is and the result is recorded here.

## Review fixes (2026-10-14)

The code review of the measured version found ten problems, all about which
lines count as headings, not about scores. They were fixed before merging,
under one condition set beforehand: the fixed code goes in only if it still
passes rules 1-5, else the measured version goes in and the fixes wait.

- `I.`, `V.`, `X.` right after `H.`, `U.`/`Ü.`, `W.` continue a lettered list
  instead of opening a Roman one.
- An outline number (`A.`, `IV.`) starts a heading only after a line that ends
  a sentence, a heading or a blank line, so an initial in wrapped prose
  (`M. Kemal Atatürk'ün …`) stays body text.
- `PART`/`SECTION`/`CHAPTER`/`BÖLÜM` rank a line as part or chapter only when
  a number follows (`BÖLÜM 2`) or, for `KISIM`/`BÖLÜM`, an ordinal precedes;
  `PART NO` is an ordinary title.
- A heading text on at least 3 pages and half of the pages of a PDF is a
  running header and stays body text; one-word warning labels (`UYARI`,
  `DİKKAT`, `WARNING`) are not titles.
- A part or chapter takes the name on the next line
  (`BİRİNCİ KISIM - Genel Esaslar`); a title in capitals wrapped over two lines
  is one title.
- `-- name --` keeps only the name; a footnote number glued to a title
  (`ANAYASASI1`) is dropped; a title spaced out with one wide gap is still a
  title (columns now need two gaps).
- `-- name --` sections nest under a title in capitals (levels: part 1,
  chapter 2, capitals 3, dashed 4, Roman 5, letter 6).

Against B, three probes lost a fact. Two of them are correct answers the
string check misses: `v2-ans-011` answers "10 iş gündür" and `v2-ans-038`
"2 iş gündür", while the probes accept only "iş günü" (the set is frozen;
reported to the owner of `v02-answers.jsonl`). One is a real loss:
`v2-ans-016` gives the catalogue's 5 years but not the specification's
60 months. Counting the two correct answers, expected facts are 0.925, the
same as 0.3.0-alpha.3.

## Decision

Adopted with the review fixes (D-024): rules 1-5 pass for the final code.
Retrieval gains (0.909 → 0.920) and shorter prompts; answers are as correct
as before. The chunker version is not bumped, so existing collections
keep working and get headings on their TXT and PDF documents when reindexed.
