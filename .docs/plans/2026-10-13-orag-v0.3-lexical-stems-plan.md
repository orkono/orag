**Goal:** First measure why questions miss (candidate absent from both lists, or present
but fused out of the answer context), then find single passages that a Turkish question asks for in another inflected form
(`dinlenmeyi` for `Dinlenmek`), by adding a short prefix stem of each long query word to the
lexical query, and adopt it only if a rule written before scoring says so.

**Architecture:** Query side only (D-006): `LexicalQuery` gains an optional `stem_chars`;
for every query term longer than that which has a letter and no digit, the MATCH expression
also ORs its first `stem_chars` characters as an FTS5 prefix term. No reindex, no
`LEXICAL_VERSION` bump, no model call, no schema change. Variants are scored with the hidden
`orag eval retrieval --lexical-query` flag; the served default (`LEXICAL_QUERY` in
`retrieval/hybrid.rs`) changes only if the decision rule passes.

**Tech Stack:** Rust 1.98.1, rusqlite (bundled) FTS5 `unicode61 remove_diacritics 0`,
`unicode-normalization` (pinned), the `orag eval` harness.

**Spec:** `.docs/orag-decisions.md` D-006 ("Deferred. Stemming … added only if the evaluation
set shows a gain"), D-018 (frozen v0.2 set, dev tunes, holdout confirms), D-005 (fusion, not
changed here); evidence in `.docs/benchmarks/v0.3-set-rewrite.md`.

## Review Focus

1. Multi-byte words (`çalışmalarını`): the stem must be cut by characters, never bytes; a
   byte slice panics on `ş`. Pinned in Task 1.
2. Codes and numbers (`DS-1600`, `53a`, `2016/347`, `E-23`): a term with any digit is never
   stemmed, so `1600` cannot become `1600`* → `16000`. Pinned in Task 1.
3. A stem equal to a term already in the query (`dinle dinlenmeyi`): no duplicate prefix
   term, which would double its BM25 weight. Pinned in Task 1.
4. A cut that lands before a combining mark (`abcdx\u{301}yz` at 5): the mark stays with its
   base letter, so FTS5 sees the same token boundaries as the index. Pinned in Task 1, and
   against real FTS5 in Task 2.
5. Deeper ranks must not change any metric: `--rank-depth 50` gives the same recall,
   MRR, nDCG and in-context numbers as the default, only longer `ranks`. Pinned in Task 0.
6. A very long question: terms stay capped at `MAX_QUERY_TERMS` (32) and stems at one per
   term, so the expression has at most 64 terms. Pinned in Task 1.

```rust
use crate::domain::normalize::lexical_terms;
use unicode_normalization::char::is_combining_mark;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct LexicalQuery {
    /// Terms of at least this many characters that contain a letter also
    /// match words they begin (`"dil"*` finds `dili`), so a Turkish suffix does
    /// not hide a match. Numbers stay whole: `104` must not find `1040`.
    pub prefix_min_chars: Option<usize>,
    /// Terms longer than this many characters with a letter and no digit also
    /// add their first characters as a prefix term (`dinlenmeyi` adds
    /// `"dinle"*`, which finds `dinlenmek`): a crude Turkish stem (D-006).
    pub stem_chars: Option<usize>,
}

/// Stems shorter than this match too much to help.
const MIN_STEM_CHARS: usize = 3;

impl LexicalQuery {
    /// Whole terms only: the behaviour before 0.2.0-alpha.4.
    pub const EXACT: LexicalQuery = LexicalQuery {
        prefix_min_chars: None,
        stem_chars: None,
    };

    /// `exact` or `prefix:<n>`, optionally followed by `+stem:<m>` (m >= 3).
    pub fn parse(text: &str) -> Option<LexicalQuery> {
        let (base, stem) = match text.split_once('+') {
            Some((base, stem)) => (base, Some(stem)),
            None => (text, None),
        };
        let prefix_min_chars = match base {
            "exact" => None,
            other => Some(positive(other.strip_prefix("prefix:")?)?),
        };
        let stem_chars = match stem {
            None => None,
            Some(stem) => Some(
                positive(stem.strip_prefix("stem:")?).filter(|&n| n >= MIN_STEM_CHARS)?,
            ),
        };
        Some(LexicalQuery { prefix_min_chars, stem_chars })
    }

    pub fn name(self) -> String {
        let base = match self.prefix_min_chars {
            Some(n) => format!("prefix:{n}"),
            None => "exact".into(),
        };
        match self.stem_chars {
            Some(n) => format!("{base}+stem:{n}"),
            None => base,
        }
    }

    /// The MATCH expression: every term quoted (so no user input reaches
    /// FTS5 syntax) and OR-ed, then the stems. `None` when the question has
    /// no terms.
    pub fn fts_query(self, input: &str) -> Option<String> {
        let terms = lexical_terms(input);
        if terms.is_empty() {
            return None;
        }
        let quoted: Vec<String> = terms.iter().map(|term| self.quote(term)).collect();
        let stems = self.stems(&terms, &quoted);
        Some(quoted.into_iter().chain(stems).collect::<Vec<_>>().join(" OR "))
    }

    fn quote(self, term: &str) -> String {
        match self.prefix_min_chars {
            Some(min) if term.chars().count() >= min && term.chars().any(char::is_alphabetic) => {
                format!("\"{term}\"*")
            }
            _ => format!("\"{term}\""),
        }
    }

    /// One prefix term per stemmable term, skipping any already present.
    fn stems(self, terms: &[String], quoted: &[String]) -> Vec<String> {
        let Some(n) = self.stem_chars else {
            return Vec::new();
        };
        terms
            .iter()
            .filter(|term| {
                term.chars().count() > n
                    && term.chars().any(char::is_alphabetic)
                    && !term.chars().any(char::is_numeric)
            })
            .map(|term| format!("\"{}\"*", stem_of(term, n)))
            .fold(Vec::new(), |mut stems, stem| {
                if !quoted.contains(&stem) && !stems.contains(&stem) {
                    stems.push(stem);
                }
                stems
            })
    }
}

fn positive(text: &str) -> Option<usize> {
    text.parse().ok().filter(|&n| n > 0)
}

/// The first `n` characters of `term`, plus any combining marks that follow
/// them, so a mark is never cut from its letter.
fn stem_of(term: &str, n: usize) -> String {
    let mut chars = term.chars();
    let head: String = chars.by_ref().take(n).collect();
    let marks: String = chars.take_while(|&c| is_combining_mark(c)).collect();
    head + &marks
}
```

import json, sys
def ranks(path):

def paired(base, variant, split):
